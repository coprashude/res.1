# ProResume AI - Modern Career & Resume Studio

A commercial-grade, multi-tool Career & Resume Suite built with **React 18, Vite, Node.js, Express, and Lucide Icons**.

---

## 🚀 Complete Suite of Features

### 1. Core Navigation & Action Header
- **Visual Editor**: Real-time side-by-side editing with live A4 sheet preview.
- **My Resumes Dashboard**: Create, clone, rename, and manage tailored resumes for different roles.
- **Cover Letter Generator**: Auto-composes professional 3-paragraph letters aligned with target job postings and your resume.
- **Job Match & ATS Keyword Analyzer**: Paste job descriptions to calculate match %, view matched keywords, and add missing skills with 1 click.
- **AI Mock Interview & Prep Simulator**: Interactive role-specific interview coaching with instant STAR-method grading.
- **Real-Time ATS Meter**: Live 0–100% score pill in the header with a slide-out detailed audit drawer.
- **AI Copilot Floating Assistant**: Chatbot assistant available anywhere across the app.

### 2. Live Customization & Layout Engine
- **8 Modern & ATS Resume Templates**: Toronto, Stockholm, New York, Vienna, Sydney, London, Dublin, Moscow.
- **Multi-Page Break Indicator**: Visual red dashed A4 cutoff line showing exact page 1 / page 2 boundaries.
- **Palette & Typography**: 6 color schemes + 6 font pairings + spacing density controls.

### 3. Editor & Content Solutions
- **Local Photo Upload**: Direct file picker (`<input type="file">`) with circular crop preview.
- **Item Reordering**: Move Up / Move Down buttons on all experience, education, and project cards.
- **AI Bullet Enhancer**: Generates high-impact action verbs and quantifies business metrics.
